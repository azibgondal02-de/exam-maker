Features

Built for Pakistani
educators, not generic use

Every feature is designed around how Pakistani teachers actually work — board patterns, bilingual needs, and curriculum structure.

Exact board pattern
Auto-generates Objective, Short Q, and Long Q sections in the correct structure for each board — Punjab, KPK, Federal.
Bilingual in one click
Every question prints in both Urdu and English simultaneously. Switch to either language alone with one toggle.
Full control
Choose chapters, topics, question types, marks per section, choice options, and question count — all configurable.
Hand-pick questions
Browse the full question bank and select exactly which questions go into the paper. Search by keyword or topic.
Inline editing
Edit any section heading, student info fields, question text, or marks directly in the paper preview.
PDF & print ready
Export to PDF or print directly. Choose fonts including Urdu Nastaliq, font sizes, and layout before output.
